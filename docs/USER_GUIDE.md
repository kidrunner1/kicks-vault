# คู่มือผู้ใช้ KicksVault

เอกสารนี้อธิบาย flow หลักของลูกค้า ตั้งแต่เข้าร้านจนถึงติดตามออเดอร์

## 1. สมัครสมาชิกและเข้าสู่ระบบ

ผู้ใช้สามารถสมัครและเข้าสู่ระบบผ่านหน้า:

- `/register`
- `/login`

หลังเข้าสู่ระบบแล้วจะเข้าใช้งานส่วนที่ต้องมี session ได้ เช่น cart, account, address book และ order history

## 2. เลือกดูสินค้า

หน้าสินค้าหลักอยู่ที่ `/product`

ผู้ใช้สามารถ:

- ดูสินค้าตามกลุ่มผู้ใช้ เช่น ผู้ชาย ผู้หญิง เด็ก
- ค้นหาด้วยชื่อสินค้า แบรนด์ คำอธิบาย หรือหมวด
- กรองตามราคาและ stock
- เรียงตามสินค้าใหม่ stock มากสุด ราคาต่ำไปสูง หรือราคาสูงไปต่ำ
- เข้าไปดูรายละเอียดสินค้าแต่ละคู่ที่ `/product/[slug]`

ในหน้ารายละเอียดสินค้าจะเห็น:

- รูปสินค้า
- ราคา
- รายละเอียดและ specs
- size และ stock ที่มีจริง
- สินค้าแนะนำที่ใกล้เคียงกัน

## 3. ตะกร้าสินค้า

ตะกร้าอยู่ที่ `/cart`

ผู้ใช้ต้องเลือก size ก่อนเพิ่มสินค้าลงตะกร้า เพราะ stock ถูกจัดเก็บแยกตาม size

ข้อควรรู้:

- Cart เป็น client-side state ผ่าน Zustand
- Cart ยังไม่ persistent ข้ามเครื่องหรือข้าม browser
- ตอน checkout ระบบจะไม่เชื่อราคาจาก cart แต่จะคำนวณจาก database อีกครั้ง

## 4. ที่อยู่จัดส่ง

ผู้ใช้จัดการที่อยู่ได้ที่ `/account/addresses`

ผู้ใช้สามารถ:

- เพิ่มที่อยู่หลายรายการ
- ตั้งที่อยู่ default
- แก้ไขหรือลบที่อยู่
- เลือกที่อยู่ที่จะใช้ตอน checkout

เมื่อสร้างออเดอร์ ระบบจะ snapshot ข้อมูลที่อยู่ลงใน `Order` เพื่อให้ประวัติออเดอร์ไม่เปลี่ยนตามที่อยู่ที่ถูกแก้ภายหลัง

## 5. Checkout และ payment mock

เมื่อ checkout สำเร็จ ระบบจะสร้างออเดอร์และพาไปหน้า `/order-success/[id]`

ระบบ payment ตอนนี้เป็น mock:

- `MANUAL` - ถือว่าจ่ายแล้วทันที
- `BANK_TRANSFER` - ยังไม่ชำระ รอ admin ตรวจ
- `COD` - ยังไม่ชำระ รอยืนยันภายหลัง

ยังไม่มีการตัดเงินจริงหรือเชื่อม payment gateway

## 6. ประวัติออเดอร์

ดูออเดอร์ได้ที่ `/account/orders`

มี tab หลัก:

- กำลังดำเนินการ - `PENDING`, `PROCESSING`, `SHIPPED`
- ทั้งหมด - ทุกสถานะ
- ส่งสำเร็จ - `DELIVERED`
- ยกเลิกแล้ว - `CANCELLED`

เมื่อออเดอร์ถูกยกเลิก จะไม่แสดงใน tab กำลังดำเนินการ แต่ยังอยู่ในประวัติและเปิดดูรายละเอียดได้

## 7. การยกเลิกออเดอร์

ผู้ใช้สามารถยกเลิกออเดอร์เองได้เมื่อ:

- ออเดอร์ยังเป็น `PENDING`
- ยังอยู่ภายใน 30 นาทีหลังสร้างออเดอร์
- ออเดอร์ยังไม่ถูกยกเลิกหรือคืน stock ไปแล้ว

เมื่อยกเลิกสำเร็จ:

- `Order.status` เปลี่ยนเป็น `CANCELLED`
- ระบบบันทึกเหตุผลการยกเลิก
- ระบบคืน stock กลับให้ size ที่ถูกสั่งซื้อ
- ถ้าจ่ายแล้ว mock payment จะกลายเป็น `REFUNDED`
- ออเดอร์ถูกย้ายไป tab ยกเลิกแล้ว

## 8. Account center

หน้า `/account` เป็นศูนย์บัญชีผู้ใช้

จะแสดง:

- ยอดซื้อสะสม
- ออเดอร์ที่กำลังดำเนินการ
- ที่อยู่หลัก
- favorite ล่าสุด
- checklist ความพร้อมของบัญชี

ยอดซื้อสะสมไม่นับออเดอร์ที่ยกเลิกแล้ว
